# Governance

This repository contains the organizational authority documents for [Open Operational State](https://github.com/open-operational-state) — a vendor-neutral effort to standardize machine-readable operational state for web services.

## Contents

| Document | Purpose |
|---|---|
| [CHARTER.md](CHARTER.md) | Initiative charter — mission, scope, and organizational identity |
| [GOVERNANCE.md](GOVERNANCE.md) | Decision-making model, roles, and authority |
| [SCOPE.md](SCOPE.md) | v1 scope definition and scope expansion policy |
| [PRINCIPLES.md](PRINCIPLES.md) | Design philosophy, neutrality, and extensibility |
| [GLOSSARY.md](GLOSSARY.md) | Controlled terminology definitions |
| [ROADMAP.md](ROADMAP.md) | Phased roadmap |
| [STEWARDSHIP.md](STEWARDSHIP.md) | Stewardship and maintainer model |
| [decisions/](decisions/) | Architecture Decision Records (ADRs) |
